# Ad Placr for TemeCMS

Operating notes for the next agent or person who opens this package cold.

## What it does

Ad Placr places an administrator's ad code inside published articles: after a paragraph, before or after the content, every N paragraphs, beside a heading, or near the end. Each ad has a status, optional mobile code, a second weighted version, display rules and optional statistics. It is a port of the WordPress plugin of the same name; what could not be ported is in `FEATURES.md`.

## Capabilities and hooks (`teme-plugin.json`)

- `content.insert`: the plugin class implements `InsertionContributor`. No hooks are listened to.
- `routes.public`, `jobs`: statistics (beacon route and retention job).
- Settings group `plugin.adplacr`; the ads are numbered slots, generated by `build/manifest.php`. Do not edit the `contributes.settings` part of `teme-plugin.json` by hand; change `build/manifest.php` and run `php build/manifest.php`.

## Run the tests

From this folder (the Teme dev site is `..\teme-dev`, its database stack is `dev/docker-compose.yml`):

```powershell
docker compose -f dev/docker-compose.yml up -d
powershell -File dev\test.ps1
```

Formatting and static analysis, with the site's own tools:

```powershell
..\teme-dev\vendor\bin\pint.bat --config ..\teme-dev\pint.json src tests build database
..\teme-dev\vendor\bin\phpstan.bat analyse src --level=6 -a ..\teme-dev\vendor\autoload.php
```

## Teme 1.0.0

The plugin asks for Teme `^1.0` and the tests set `teme.version` to `1.0.0`. A plugin with `schedules` is enabled with `php artisan teme:plugins:enable krafty-sprouts/adplacr --agree --as=<administrator email>`, and `JobContext` has `personId()`. On the shared dev site, `TEME_VERSION=1.0.0` must be set in its `.env`. Where the work stopped and what to build next is in `REPORT.md` ("Where I stopped").

## Rules this package keeps

Code only against `teme/contracts`; every CSS class, id and JS global starts with `adplacr`; tables start with `adplacr_`; no secrets, no calls home, statistics off until an administrator turns them on.
